# Road Accident Analysis

This repository contains an end-to-end data analysis project focusing on road accident data to identify key patterns, trends, and safety insights.

Project Overview:
The objective of this project is to analyze comprehensive road accident datasets to uncover critical insights related to accident hotspots, severity factors, vehicle involvement, and time-based trends. 

Tools & Technologies Used:
Data Analysis & Processing: Microsoft Excel
Database & Queries: SQL
Data Visualization & Dashboard: Power BI 

Repository Structure:
Dataset- Contains the raw dataset files.
Queries- Contains SQL script files used for data extraction and querying.
Reports - Contains the interactive Power BI dashboard reports. 

Key Insights:
Identified peak accident hours and high-risk days of the week.
Analyzed the core factors contributing to accident severity.
Built interactive dashboards to visualize geographic and categorical accident distributions.
